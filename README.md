# Sang Pham — Portfolio

Personal portfolio of Sang Pham, Business Analyst & Product Designer based in Da Nang, Vietnam.

A static site (plain HTML, CSS and JavaScript, no build step):

- `index.html` — home: intro, selected projects, what I do, contact
- `about.html` — about me, philosophy, career journey
- `img/`, `fonts/` — assets

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deploy

The site deploys as-is to GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
